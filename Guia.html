Guia de Tecnologia

Como escolher um computador?

Antes de comprar um computador, e importante observar quais atividades serao realizadas.

Um equipamento utilizado apenas para navegar na internet e estudar possui necessidades diferentes de um computador utilizado para jogos ou edicao de videos.

Processador

O processador e responsavel por executar as instrucoes dos programas.

Alguns exemplos de fabricantes sao:

  • Intel
  • AMD

Memoria RAM

A memoria RAM armazena temporariamente os dados que estao sendo utilizados pelo computador.

Quanto maior a quantidade de memoria disponivel, maior pode ser a capacidade do computador de trabalhar com varias aplicacoes simultaneamente.

Armazenamento

Os principais tipos de armazenamento encontrados atualmente sao:

  • HD
  • SSD SATA
  • SSD NVMe

Qual escolher?

HD

Indicado quando e necessario grande espaco de armazenamento por um custo menor.

SSD

Oferece maior velocidade de acesso aos dados em comparacao com um HD tradicional.

SSD NVMe

Utiliza uma interface de comunicacao voltada para oferecer altas velocidades de transferencia.

Glossario de informatica

CPU
Unidade responsavel pelo processamento das instrucoes.
RAM
Memoria utilizada temporariamente durante a execucao dos programas.
SSD
Dispositivo utilizado para armazenamento de dados.
GPU
Componente responsavel pelo processamento grafico.
